# HTML-Task

## Project Description
This repository contains a collection of Taskes about HTML created to demonstrate fundamental HTML concepts such as forms, lists,tables using HTML without any CSS.

## Pages Included
* **`Form.html`**: An application form that includes ==>  text inputs, date pickers, dropdown selection menus, radio buttons, checkboxes, password fields, and action buttons.
* **`Lists.html`**: Examples of ordered lists with descending numbers, nested bulleted lists, and mixed hierarchical lists.
* **`Table.html`**: A structured table utilizing HTML attributes such as (`border`, `cellpadding`, `cellspacing`, `bgcolor`), as well as column spanning (`colspan`) and row spanning (`rowspan`) as well as table align.
